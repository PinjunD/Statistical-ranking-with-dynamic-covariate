# Statistical-ranking-with-dynamic-covariate
This is the code file for the paper "[Statistical ranking with dynamic covariate](https://arxiv.org/abs/2406.16507)".<br>
Author: Pinjun Dong, Ruijian Han, Binyan Jiang, Yiming Xu (Authorships are ordered alphabetically).<br>

## Documents:
#### data
This document contains simulation results, as well as tennis and horse racing data. The tennis data is sourced from [Jeff Sackmann](https://github.com/JeffSackmann/tennis-atp), while the horse racing data is from [Hong Kong horse-racing dataset](https://www.kaggle.com/datasets/gdaley/hkracing).

#### image
This document includes the figures from the simulation and real data analysis.

#### package
This document showcases the algorithm and synthetic data generator introduced in our paper.
## Files:
#### illustration.ipynb
This file introduces a specific example to demonstrate our methods.
#### simulation.ipynb
This file details the process of simulating synthetic data.
#### tennis.ipynb
This file outlines the process of analyzing tennis data.
#### horse racing.ipynb
This file explains the process of analyzing horse racing data.
